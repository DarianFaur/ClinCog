History & backup

What changed on this console and when, with undo, and a copy of the settings you can restore after a mistake.

History

Every change made on this console, newest first, with the last 50 kept. Undo puts the settings back as they were before that change; changes made after it are undone with it, and the undo itself is written here too.

Backup

A copy of every seminar setting as a file: students, limits, periods, schedule, announcements, provider, budget and demo. API keys and the class password are never in it, so it can be kept anywhere; restoring leaves the current ones in place.
