Adopt this platform

ClinCog is free to try, right here on this domain — but every conversation you have on this page draws from the author's own API budget, which is why it's kept deliberately modest for casual use.

There are two different ways to adopt ClinCog for a real class, depending on how much control you want.

Option A · Quick

Bring your own key, right here

  • Two minutes, no account beyond an Anthropic API key
  • Still runs through ClinCog's own server (this domain)
  • Your key lives only in this browser — see below for the form
Use this option ↓
Option B · Full independence

Deploy your own copy

  • ~30-45 minutes, no coding experience needed
  • Runs on your own Cloudflare account, nothing touches this server
  • Your own domain (or a free one), your own budget, full control
Read the full guide on GitHub →

Continuing below sets up Option A. Your keys are stored only in this browser's local storage. They're sent to ClinCog's server with each request — used for that single call, then discarded — never logged, never saved anywhere server-side.
