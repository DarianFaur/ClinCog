CANTAB – Cambridge Neuropsychological Test Automated Battery
Used in Darren's case (depression) – Spatial Working Memory and One Touch Stockings

CANTAB is a computerised, touchscreen neuropsychological battery developed at the University of Cambridge and now maintained commercially by Cambridge Cognition. Its tasks are largely language- and culture-independent, which has made it a common choice across neurology, psychiatry, and pharmacology trials – dementia, schizophrenia, depression, Parkinson's disease, and others.

Spatial Working Memory (SWM)

A number of coloured boxes are shown on screen. The participant searches them one at a time to find a hidden yellow token, using the rule that once a token has been found in a box, that box will not hide a token again for the rest of that trial – so returning to a box already emptied is an error. Box count increases across trials (up to 12). The key outcome, between errors, counts returns to boxes already shown to be empty; a separate strategy score captures how systematically the participant searches (e.g., always starting from the same box). It is described by Cambridge Cognition as sensitive to frontal-lobe / executive dysfunction.

One Touch Stockings of Cambridge (OTS)

Based on the Tower of London / Tower of Hanoi paradigm. Two displays of three coloured balls, shown as if held in stockings hanging from a beam, are presented; the participant must work out – without moving anything – the minimum number of moves needed to turn the lower display into the upper one, then touch the number box showing that answer. It measures spatial planning and working memory together, and is treated as a marker of frontal/executive function.

In a study using an automated neuropsychological battery (CANTAB) with 30 patients with major depressive disorder (10 currently symptomatic, 10 remitted, 10 healthy controls), the symptomatic group showed significant dysfunction on almost every test administered except IED (set-shifting) and MTS (matching to sample); visual memory was the most impaired domain. The remitted group still showed significant dysfunction except on IED, RTI (reaction time), and SOC (Stockings of Cambridge) – consistent with the broader finding that some CANTAB-measured deficits in depression persist beyond the symptomatic episode (Egerházi et al., 2013).
